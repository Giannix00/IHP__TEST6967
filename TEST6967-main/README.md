# TEST6967-main

Working directory of the top cell `TEST6967`.

- The layout was generated with the authors' own Python/KLayout scripts, which are not part of this repository.
  The released layout (seal ring and filler included) is
  [`release/v.1.0.0/gds/TEST6967.gds`](../release/v.1.0.0/gds/TEST6967.gds).
- There is no schematic: the chip contains no devices, only metal lines, pads and ground on Metal1 ... TopMetal1.
  The LVS netlist is [`release/v.1.0.0/netlist/TEST6967.cdl`](../release/v.1.0.0/netlist/TEST6967.cdl).
